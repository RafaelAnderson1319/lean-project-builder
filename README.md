# Lean Project Builder

Regras de economia para este projeto (siga em todas as mensagens):

1. Faça tudo em uma única execução. Não pare para pedir confirmação nem faça perguntas, a menos que falte uma informação essencial.

2. Mantenha exatamente a mesma estrutura de páginas, rotas e seções que já usa. Não adicione páginas, funcionalidades ou seções extras que eu não pedi.

3. Crie componentes reutilizáveis (Header, Footer, Section, Card, Button) e use-os em todas as páginas em vez de repetir código.

4. Edite apenas os arquivos necessários. Não reescreva, refatore ou reformate arquivos que não precisam mudar.

5. Use textos e imagens placeholder curtos. Eu ajusto o conteúdo depois.

6. Estilo simples e consistente: use as variáveis e o design system já definidos (cores, fontes, espaçamentos) e evite animações complexas, efeitos pesados e dependências novas.

7. Não gere documentação, README, testes nem comentários extras no código.

8. Respostas curtas: no final, diga só uma linha com o que foi alterado, sem explicações longas.

9. Se algo der erro, corrija apenas o erro, sem reestruturar o restante.
